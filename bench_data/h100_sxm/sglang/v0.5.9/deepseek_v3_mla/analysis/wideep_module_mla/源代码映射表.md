### 2.2 口径 4：real_wideep_aligned_gpu_makespan_ms

源代码中的 sum_child_makespan_bounds_ms() 函数：

def sum_child_makespan_bounds_ms(row, names: set[str]) -> float | None:
    """
    计算 WideEP 对齐子模块的 GPU makespan
    逻辑：从首个子模块的首个 kernel 开始
          到末个子模块的末个 kernel 结束
          的时间跨度
    """
    child_timings = json.loads(row.get("child_timing_json", "[]"))
    selected = [
        child for child in child_timings 
        if child.get("canonical_name") in names
    ]
    
    starts = [
        float(child.get("first_kernel_start_ns"))
        for child in selected
        if child.get("first_kernel_start_ns") is not None
    ]
    ends = [
        float(child.get("last_kernel_end_ns"))
        for child in selected
        if child.get("last_kernel_end_ns") is not None
    ]
    
    if not starts or not ends:
        return None
    
    # makespan = (max_end - min_start) / 1e6 (convert ns to ms)
    return (max(ends) - min(starts)) / 1e6

### 2.3 口径 5：real_wideep_aligned_gpu_kernel_time_sum_ms

源代码中的 sum_child_gpu_ms() 函数：

def sum_child_gpu_ms(row, names: set[str]) -> tuple[float, int]:
    """
    计算 WideEP 对齐子模块的 GPU kernel 时间加总
    返回：(总时间_ms, kernel_count)
    """
    child_timings = json.loads(row.get("child_timing_json", "[]"))
    
    total_ms = 0.0
    count = 0
    
    for child in child_timings:
        if child.get("canonical_name") in names:
            total_ms += float(child.get("gpu_kernel_time_sum_ms") or 0.0)
            count += int(child.get("gpu_kernel_count") or 0)
    
    return total_ms, count

### 2.4 口径 6：real_wideep_aligned_host_duration_sum_ms

源代码中的 sum_child_host_ms() 函数：

def sum_child_host_ms(row, names: set[str]) -> float:
    """
    计算 WideEP 对齐子模块的 host duration 加总
    """
    child_timings = json.loads(row.get("child_timing_json", "[]"))
    
    total_ms = 0.0
    for child in child_timings:
        if child.get("canonical_name") in names:
            total_ms += float(child.get("host_duration_ms") or 0.0)
    
    return total_ms
