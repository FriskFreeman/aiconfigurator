## 🔍 关键概念速查

### 配置优先级 (从高到低)
1. **命令行参数** (最高)
2. **ServerArgs 设置**
3. **Pipeline 配置类** (如 Wan2_2_T2V_A14B_Config)
4. **HF config.json** (架构定义)
5. **基类默认值** (最低)

### 三种配置来源
- **HF 官方** (model_path/config.json): 模型架构参数
- **SGLang 类定义**: 运行时优化参数
- **启动参数**: 用户指定的配置

### 关键数据维度计算

```
隐藏维度 (hidden_size)
  = num_attention_heads × attention_head_dim
  = 40 × 128 = 5120

补丁数 (num_patches)
  = (frames / patch_size[0]) 
    × (height / patch_size[1]) 
    × (width / patch_size[2])
  = (9 / 1) × (30 / 2) × (40 / 2)
  = 9 × 15 × 20 = 2700

FFN 中间维度
  ≈ hidden_size × 2.7 = 5120 × 2.7 = 13824

文本序列长度
  = 512 (或 max_len)

文本特征维度
  = text_dim = 4096 (T5 输出)
```

### 精度选择
- **bf16**: 默认，平衡精度和速度 (推荐)
- **fp32**: 更高精度，但内存翻倍
- **fp8/int8**: 量化（不推荐用于高质量推理）

## 🎓 原理深化

### Wan 模型的核心创新
1. **Flow 扩散**: 使用流匹配而非噪声预测
2. **A2A (All-to-All) 注意力**: 支持时空联合建模
3. **补丁化处理**: 通过补丁嵌入降低序列长度
4. **多模态融合**: T2V/I2V/TI2V 统一框架

### SGLang 的配置哲学
1. **分层设计**: 架构参数与运行时参数分离
2. **映射灵活性**: 支持多种权重格式转换
3. **优化透明性**: 所有优化参数可配置
4. **性能-精度权衡**: 提供多个优化选项

### 配置文件的进化
- **版本 1.0**: 固定参数，难以优化
- **版本 2.0**: 基类 + 特定类，支持继承
- **版本 3.0** (当前): 分层配置 + 灵活映射 + 动态优化
