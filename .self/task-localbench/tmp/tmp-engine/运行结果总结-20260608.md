## 2. PCG 开启：失败

目录：
- `.self/task-localbench/tmp/tmp-engine/output/20260608_165617_sglang_engine_deepseek_v3_dummy5_pcg_on`

关键结果：
- `run_meta.txt` 中 `status=fail`、`docker_returncode=137`
- `stage.txt` 停在 `before_engine_init`
- 没有生成 `generate_response.json`
- 没有生成 `profile/*.trace.json.gz`

失败阶段：
- 初始化 `Engine` 时进入 piecewise CUDA graph 捕获
- 还没开始真正的 generate，就在 scheduler / model runner 初始化阶段失败

日志核心报错：
- `Capture piecewise CUDA graph begin`
- `install_torch_compiled`
- `torch._dynamo.exc.Unsupported: builtin isinstance() cannot determine type of argument`
- 调用链落在 `deepseek_v2.py` 的 MLA / attention 相关 forward 路径

结论：
- 在 `v0.5.9` 下，DeepSeek-V3 dummy 5层模型启用 `enable_piecewise_cuda_graph=True` 时，会在 PCG 初始化编译阶段触发 Torch Dynamo 不支持错误，导致 Engine 无法完成初始化。
- 这不是单纯 warmup 较慢，而是明确的初始化报错。

## 3. 当前可直接复用的结论

- 对我们当前的 trace 采集任务，Engine 入口比 server 入口更干净，影响因素更少。
- `v0.5.9` 下已经确认三种典型组合：
  - `disable_cuda_graph=True` + `enable_piecewise_cuda_graph=False`：成功
  - `disable_cuda_graph=False` + `enable_piecewise_cuda_graph=False`：成功
  - `disable_cuda_graph=True` + `enable_piecewise_cuda_graph=True`：失败
- 如果后续要继续研究 PCG，需要单独定位：
  - `v0.5.9` 中 DeepSeek/MLA 路径与 Torch Dynamo 的兼容性问题
  - 是否可通过改 `piecewise_cuda_graph_compiler`、模型实现路径或升级 SGLang/PyTorch 规避

## 5. 2026-06-09补充：SGLang v0.5.12 的 PCG 行为

### 5.1 不显式设置 attention backend（实际自动落到 fa3）：失败

目录：
- `.self/task-localbench/tmp/tmp-engine/output/20260609_110003_sglang_engine_deepseek_v3_dummy5_cg_off_pcg_on`

关键观察：
- 这次已经不是参数名问题；已成功把新版本参数映射成：
  - `disable_piecewise_cuda_graph=false`
  - `enforce_piecewise_cuda_graph=true`
- 日志中最终的 `server_args.attention_backend='fa3'`
- 进入了真正的 PCG compile 阶段，但在 `num_tokens=2048` 的 warmup compile 时失败

失败特征：
- 不再是 `v0.5.9` 中的 `torch._dynamo Unsupported isinstance(...)`
- 新报错变成 compiled 图里的 `torch.bmm(...)` 触发：
  - `CUDA error: CUBLAS_STATUS_EXECUTION_FAILED`

结论：
- 在 `v0.5.12` 中，默认/自动 backend 路径下，DeepSeek-V3 dummy 5层的 PCG 仍可能失败
- 这说明“新版本已经支持 DeepSeek MLA 的 PCG”不等于“任意 backend 组合都稳定可用”

### 5.3 当前阶段的更准确判断

- `backend` 对 `v0.5.12` 的 PCG 结果有明显影响
- “不显式设置 backend”并不等于中性路径；在当前环境下会自动落到 `fa3`
- 当前实测结果是：
  - `v0.5.12 + auto -> fa3 + PCG on`：失败
  - `v0.5.12 + triton + PCG on`：成功
