## 注意事项

- decode 请求当前以异步单请求 stream 方式逐条提交，因此 decode 预热阶段本身可能产生早期 mixed batch。正式分析时应筛选 `prefill.items[].rid` 以 `formal-prefill-` 开头的 mixed 记录。
- SGLang mixed 调度会把 running decode token 数从 prefill chunk 预算中扣除，因此即便 `prefill_fresh_len == chunked_prefill_size`，正式 chunk 也可能出现如 `254 + 2` 的切分，这是原生 scheduler 行为。
- 当前 runner 目标是单引擎 continuous batching mixed chunked prefill，不是 server 级 P/D disaggregation。
